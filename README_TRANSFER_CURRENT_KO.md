# 전방 카메라 마커 미션

Ubuntu 24.04, ROS Jazzy, Gazebo Harmonic 기준입니다.
새 PC 설치: `bash scripts/setup/install_ubuntu.sh`

프로젝트 루트에서 실행:

```bash
bash scripts/run_all_windows.sh --front-mission-flight --seed 100002 --domain 207
```

Gazebo·전방 흑백 카메라·깊이 표시 창이 열립니다.
종료는 Ctrl+C 또는 카메라 창의 Q/Esc이며 결과는 `DATA/front_full_mission_*`에 저장합니다.
각 실행의 카메라·시계·명령 ROS 토픽은 `/vision_trial_<실행ID>/...`로 분리됩니다.
이전 실행의 브리지가 같은 ROS 도메인에 남아 있어도 새 실행과 영상을 섞지 않습니다.

1단계는 ArUco 1~6을 순서대로 따라갑니다. 마커 네 모서리의 평균점을 카메라의
보정된 중앙점에 맞추면서 이동합니다. 도착 거리 밖에서 목표 마커가 보이면 0.50m/s까지 부드럽게
가속한 뒤 속도를 유지합니다. 중앙 오차 때문에 반복해서 가속·감속하지 않습니다.
전진 가속은 최대 0.20m/s², 가속도 변화는 최대 0.40m/s³로 제한해 가속 시작과
종료를 완만하게 만듭니다. 영상 상하·회전 정렬에는 PID를 적용합니다.
적분 누적 제한, 미분 필터, 목표 변경 시 PID 초기화로 명령 급변을 줄입니다.
이득은 `control/image_pid.py`의 `kp/ki/kd`에서 조정하며 현재 값은 비행 튜닝 전 초기값입니다.
마커까지 추정 수평 거리가 3.5m 이내가 되면 도착으로 기록합니다. 아직 중앙이
맞지 않으면 전진을 멈추고 PID 정렬을 계속합니다. 도착 후에는 거리 값이 조금
변해도 다시 접근하지 않습니다. 현재 ID를 새 영상에서 확인하고 좌우·상하 오차가
각각 10픽셀 이내가 되면 다음 마커로 전환합니다. 정렬된 상태에서 도착하고
다음 목표도 보이면 전환할 때 전진 속도를 유지합니다.
다음 마커를 찾는 데 시간 제한은 없습니다.

마커가 보이는 동안에는 상하 중앙 정렬을 위해 영상 오차로 고도를 조정합니다.
마커 탐색 중의 고도 목표는 시작 위치에서 1.5m 상승한 높이입니다. CameraInfo와
설정된 마커 크기 0.6m로 계산하며, 지면 높이 측정값은 아닙니다. 위치 계산이
없어도 마커 영상이 유효하면 중앙 정렬을 수행합니다.

사용자 요청에 따라 1단계의 근접·영상 크기 정지, 위치 점프 거부와
재확인 대기, 이륙·고도 불안정 시 수평 속도 제한, 충돌·탐색·진행·실행 시간
종료 조건을 제거했습니다. 목표 마커가 보이지 않으면 기존 제자리 탐색을 수행합니다.
영상 형식·시간 및 카메라 보정 검사는 계산 전제로 유지합니다.

2개씩을 배치합니다. 구조물은 실제 충돌 형상을 가지며 링 안쪽은 비워 둡니다.
사용자 요청으로 링 단계의 안전 중단·종료 조건과 대기·반지름 여유를 제거했습니다.

측면 이동·높이 변경·회전을 추가하던 경로 보정은 제거했습니다.
이전 보정이나 회피 명령도 통과 중에는 이어받지 않습니다. 저장한 위치와 자세는 근접 감속·기록에만 사용합니다.

# 전방 카메라 미션 설정

`profile.json`은 전방 320×320 흑백 카메라, 개발용 ArUco DICT_4X4_50,
마커 한 변 0.6m와 센서 제한을 정의합니다. 마커 크기는 검은 정사각형 기준이며
흰 테두리는 제외합니다. 공식 대회 규격으로 확정한 값은 아닙니다.

프로젝트 루트에서 현재 전체 미션 실행:

```bash
bash scripts/run_all_windows.sh --front-mission-flight --seed 100002 --domain 207
```

1단계 마커 1~6 방문 후 종료하는 확인용 실행:

```bash
bash scripts/run_all_windows.sh --front-mission-flight --seed 100002 --domain 207 --stop-after-stage1
```

Gazebo, 전방 카메라, 깊이 표시 창과 `FLOW DECK` 센서 창이 열립니다.
Flow Deck 창은 하방 영상, ToF 거리(m/mm), 광류 속도, IMU 자세와 갱신 상태를 표시합니다.
지연된 영상은 `STALE`, 유효하지 않은 속도·자세는 `--`로 표시합니다.
화면은 `scripts/runtime/flow_sensor_view.py`에서 생성하며 `--headless`에서는 열지 않습니다.
종료는 Ctrl+C 또는 카메라·센서 창의
Q/Esc이며 결과는 `DATA/front_full_mission_*`에 저장합니다.

1단계는 도착 거리 밖에서 목표 마커가 보이는 동안 0.50m/s까지 부드럽게 가속한 뒤 일정 속도를
유지하며, PID로 마커 중앙과 카메라 중앙을 맞춥니다. 중앙 오차에 따른 반복 감속은
하지 않습니다. 최대 가속 0.20m/s²와 가속도 변화 0.40m/s³를 적용합니다.
추정 거리 3.5m 이내에서 도착을 기록하고, 중앙 오차 각각 10픽셀 이내에서 다음 ID로
전환합니다. 도착 시 중앙이 맞지 않으면 제자리 정렬하며 다시 접근하지 않습니다.
정렬된 채 도착하고 다음 목표도 보이면 전진 속도를 유지합니다.
마커가 보일 때는 상하 영상 오차로 고도를 조정하고, 탐색 중에는 기존 1.5m 목표를 사용합니다.
근접·화면 크기·위치 점프에 따른 정지와 탐색 시간 제한은 제거했습니다.
1단계의 전방 학습 깊이는 표시 전용입니다.

Flow deck 하방 광류·거리는 정지 중 미끄러짐 보정, 탐색 높이 유지, 착지 감속에 사용합니다.
IMU는 영상 회전과 ToF 높이의 기울기를 보정하며 제공 지도·Gazebo 정답 위치는 제어에 사용하지 않습니다.
현재 전체 미션은 ToF 확인이 필수이므로 `sensor_assistance.flow_deck=true`여야 시작합니다.
링 구간에는 에어게이트와 건물형 장벽이 생성됩니다.
링은 YOLO 박스 중앙을 카메라 중앙에 맞춘 뒤 기존 속도로 정면 전진합니다.
YOLO는 0.10초 간격으로 추론하며 새 프레임마다 전방 링 테두리 이동을 추적합니다.
마지막 YOLO 확인 후 최대 0.60초 검출 누락을 보완하고, 작은 뒤쪽 링으로 전환하지 않습니다.
추적 근거가 없으면 최대 0.20초 제자리 재검출 대기 후 탐색합니다. 화면의 `ring TRACK`으로 구분합니다.
하방 ToF가 지면 기준보다 0.15m 이상 짧아지고(급변 0.12m 이상, 2개 표본),
다시 기준 거리−0.06m 이상으로 회복된 값이 연속 0.30초 유지되어야 다음 링으로 전환합니다.
추정 위치나 영상 확대만으로 완료하지 않습니다. 센서 누락은 통과 확인에 사용하지 않습니다.
윤곽 계산에 실패해도 YOLO 링 박스 검출은 표시와 정렬에 사용합니다.
3단계는 기존 깃발 ID 23의 0.40m 크기와 전방 카메라 PnP로 상대 거리·속도를 구합니다.
깃발까지 전방 거리 1.50m를 유지하며 왕복 차량의 전진·후진을 따라갑니다.
수평 상대 속도 0.05m/s 이하이면 즉시 하강을 시작하며, 하강 중에도 수평 추종을 계속합니다.
추종은 전후 최대 ±0.60m/s, 하강은 최대 0.10m/s이고 전방 학습 깊이는 표시 전용입니다.
깃발이 정렬된 상태에서 ToF 높이가 0.20초 이내 0.20m 이상 짧아지면 차량 위 진입으로 기록합니다.
ToF 0.06m 이하 2개 표본과 최근 근접 기록(0.70초 이내), 기존 깃발 착지 위치 조건 및
시뮬레이션 적재함 윗면 접촉이 함께 확인돼야 착륙 완료입니다. 추가 착륙 마커는 사용하지 않습니다.
영상 누락 시 정지하며, 착지 직전에는 가까운 마지막 관측과 ToF 차량 진입 근거가 있을 때만
최대 1.5초 하강을 이어갑니다. 시간 경과만으로 착륙 완료하지 않습니다.
Flow 보정은 정지·정렬 수평 ±0.05m/s, 탐색 높이 유지 ±0.06m/s 이내입니다.
깃발이 보이고 표면까지 0.28m 미만이면 하강을 0.04m/s로 낮춥니다.
링 강제 전진과 차량 수평 추종에는 Flow 속도 보정을 적용하지 않습니다.
2026-10-16 ToF 변경 후 기존 거리 기록의 첫 변화 재생을 확인했습니다. 링 추적 보완까지 포함한 오프라인 회귀 114개와 저장 영상 8장의 이동·검출 누락 시험을 통과했습니다.
로그 재생은 수평 자세 가정이며, 변경 후 Gazebo 비행·차량 착륙은 아직 확인하지 않았습니다.

이 코드는 PC에서 실행하는 시뮬레이션 개발용이며 실기체 탑재 코드가 아닙니다.
전체 미션 성공·온보드 처리 성능·실제 위치 정확도는 검증되지 않았습니다.
기본 IMU·기압계 사용 규정, GAP8/STM32 이식, 실기체 카메라 보정은 미완료입니다.

현재 설치·오프라인 검증 안내는 `../README_TRANSFER_CURRENT_KO.md`를 참고하세요.
